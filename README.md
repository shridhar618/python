# Python Projects

Beginner Python projects (console games, calculators and utilities) built while learning the fundamentals: control flow, functions, data structures, OOP and the `turtle` module.

## Projects

| Project | File |
|---|---|
| Quiz game (OOP with question model and quiz engine) | `My-Quiz/` |
| Coffee machine simulator | `coffee-machine.py` |
| Silent auction | `auction.py` |
| Treasure hunt adventure | `treasure-hunter.py` |
| Turtle race game | `turtle-race game.py` |
| Rock, paper, scissors | `stone,paper,scissor.py` |
| Number guessing game | `number-guessing game.py` |
| Follower guessing game (higher or lower) | `follower-guessing game.py` |
| Letter guessing game | `letter_guessing.py` |
| Calculator | `My-calculator.py` |
| BMI calculator | `BMI-Calculator.py` |
| Love calculator | `love-calculator.py` |
| Strong password generator | `Hard-password generator.py` |
| Message encoding (Caesar cipher) | `Message-Encoding.py` |
| Prime number check, multiplication tables, inheritance demo | `prime-number check.py`, `tables.py`, `inheritance.py` |

## Running

```bash
python3 coffee-machine.py
cd My-Quiz && python3 main.py
```

All projects use only the Python standard library.
